Claudio Hollman is the sole developer and owner of Turnocero (full-stack React + Express app for organizing Argentine board game sessions).

- Email: claudiohollman@gmail.com
- GitHub: chollman
- Native Argentine Spanish speaker; UI/content in Spanish, commit messages in English
- Full-stack developer comfortable with both React frontend and Express/Mongoose backend
- Uses the VSCode extension for Claude Code as an active pair programmer
- Works across two machines: Windows 11 PC (primary) and MacBook Pro
- Ships features iteratively — one at a time, refines via follow-up commits
- Merges PRs from feature branches but also commits directly to master for smaller changes
